# ai

A personal knowledge base about working with AI agents: how to communicate with them, how to build
with them, and what happens when organizations and societies adopt them.

Plain Markdown. No site generator, no build step. Read it on GitHub or in an editor.

## How this is organized

| Folder                        | What goes here                                                        |
| ----------------------------- | --------------------------------------------------------------------- |
| [`_incoming/`](_incoming/)    | Raw, unsorted capture. Links, quotes, half-thoughts. No structure required. |
| [`_blog/`](_blog/)            | Staging for posts: drafts and raw material waiting to be published.   |
| [`communication/`](communication/) | Prompting, context engineering, specs, feedback loops, failure modes. |
| [`aglc/`](aglc/)              | The Agentic Development Life Cycle, and how it differs from the SDLC.  |
| [`adoption/`](adoption/)      | Who takes this up and what it costs them, in three aspects:            |
| [`business/`](adoption/business/) | — organizations: org design, economics, process, risk, governance. |
| [`society/`](adoption/society/)   | — everyone else: schools, labor, policy, ethics, public understanding. |
| [`journey/`](adoption/journey/)   | — me: phases, triggers, failure modes, records of adopting a tool. |
| [`tools/`](tools/)            | Models, harnesses, MCP, evals, and the concrete tooling landscape.     |
| [`reference/`](reference/)    | Glossary, reading list, source notes.                                  |

Ideas arrive faster than they can be organized, so the two `_`-prefixed folders are staging areas.
Raw material lands in `_incoming/`; once its substance is folded into a topic note the original is
deleted. Things worth writing about publicly get staged in `_blog/` until the post lands on the
website, then those are deleted too. Both folders trend toward empty, and git keeps what was
removed — a note that has been superseded is a note that will mislead somebody later.

Start anywhere — each topic folder has a `README.md` listing what is in it.
