# 2026-08-22

## 1000am Theo: I'm done with terminals

[I'm done with terminals](https://www.youtube.com/watch?v=dLhcLqoff6k)

Erklärt, warum er nicht so gern mit Terminals arbeitet, was die Probleme sind bei den Terminal basierten CLIs:

- Images Pasten
- Zugriff auf alle Modelle in einer UI
- gute Fernsteuerung
- Linux-Support, weil das Linux-Dateisystem für die agentische Arbeit sehr gut geeignet ist.
  Hierzu ein separates Video.
- Mobile-Support
- gute Performance
- niedriger Impact auf die Laptop-Batterie (aka Meetings mit Lüftern bei 100%)
- viele Terminals managen, was selbst mit tmux oder cmux immer schwierig blieb
- In Projekte umbenennen, gruppieren, organisiseren

Er nennt die Codex-App als Vorbild, sagt allerdings, seit ChatGPT integriert wurde gibt es viele Dinge, die er als Dev nicht braucht.

Theo pitcht T3 Code als Open-Source-Projekt, was alle diese Probleme adressiert, aus einem Need heraus, den er un Julius selbst hatten.
Er glaubt, dass die Entwicklungstools Open Source sein sollen. Er glaubt, dass es wichtig ist, dass man etwas hat, was man den großen Labs quasi entgegensetzen kann und was man vor allem customizen kann. Man ist sonst von den Labs abhängig: In welche Richtung sie gehen, welche Features sie einbauen. Es gibt jede Menge Regressions. Claude CLI wird gedoggfooded und entsprechend sind Features und UX (das kann ich bestätigen)

Hauptargumente für T3Code: 

- das Interface: Pasten von Images funktioniert, Text sieht gut aus
- voll nativer Zugriff auf die Agenten via offiziellen SDK
- sehr gute Steuerung für Remote, also was auf welcher Box ausgeführt wird
- Zugriff über Browser rein, Mobile App oder die Desktop-App

Für mich könnte das in der Tat herdr ersetzen.
