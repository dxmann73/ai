# First principles for an agentic world

## Context matters

- context decides outcomes
- key factor for success: WHAT IS IN THE CONTEXT
- context window size: hand over, split up

## Treat agents as colleagues

- Communicate efficiently, give context, align, verify, give feedback.
- Give them memory and a2a communication => Improvement over time, better results
- Agents aren't humans. They don't have the same inhibitions. They may act ruthlessly and still be innocent.

## Keep the humans in the loop

- Burnout, working with agents is draining
- Comprehension rot, inability to work on the product
- There ARE solutions for this, needs a certain approach (which eat into the productivity gains)
